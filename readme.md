<h1>Chaos Collider</h1>
<h3>About the Game:</h3>
<p>Vhaos Collider is a fun and arcade themed game made with HTML/CSS/JS.In this game, You have to break the bricks using the shiny ball.There are powerups that drops while you play the game, these powerups make the game more fun and intresting.</p>

<h3>Controls</h3>
<p>To play the game you need to know controls to so here is the controls guide:</p>
<p>1.You can move mouse to move the paddle left and right.</p>
<p>2.You can click to release the ball and start the game.</p>
<p>3. Make sure to collect powerups and watch the score up there.</p>

<h3>How to run it?</h3>
<p>You can run this game by just following these simple steps:</p>
<p>1. Download VS Coode and Fork this repository to your github.</p>
<p>2. Clone this repository and install Live Server extension to the VS Code</p>
<p>3. Click the Go Live button in the bottom right corner of your VS Code screen.</p>
<p>4. You can now customize the code to customize the experience yourselfs too now and ENJOY.</p>
